# 交付与验收清单

基线：`f3c0a82`。本清单跟踪尚未闭环的功能，不替代[实现状态](implementation-status.md)或逐项[验收记录](architecture-acceptance.md)。每批先跑定向回归，再跑适用的工作区和插件检查，最后本地提交。区分代码完成、本机通过与目标宿主验收。

| 批次 | 范围 | 完成判据 |
| --- | --- | --- |
| 1a · 本机已验证 | Wiki 重建 | 扫描、单文件和总读取有界；文件 IO/解析不占用 Wiki 写事务；输入异常或受管账本换代时不发布旧代次；索引原子替换。 |
| 1b · macOS 已验证 | Sediment / Fact Pack | 逐个核对存量安全门禁、输入与序列化上限、ACL、目标别名和耐久发布；冲突不覆盖，失败重试不会追加重复事件。 |
| 2 · 本机已验证，托管 CI 待实跑 | Lean 隔离与原生 CI | 前驱对象在新模块构建时只读；T1/T3/回归和关键恢复用例在固定原生工具链上运行，默认忽略不等于验收。用 [native-lean.sh](../.github/native-lean.sh) 在允许 Broker 启动 Seatbelt 的 macOS 宿主复验。 |
| 3a · 本机已验证 | DeepSeek 单任务进程 | 不合作任务硬截止，取消后回收直接子进程，拒绝迟到响应，父进程强退触发生命线 EOF；已用本机已安装的 Electron SDK 和本地 Messages 夹具验收两种角色。未使用生产凭据或远端服务。 |
| 3b-1 · 本机已验证 | 持久单次派单 | 操作者批准精确 Git 快照、任务、角色、模型和预算；审批消费、租约和审计同一事务。进程中断或确认丢失后不自动重派。 |
| 3b-2 · 有限驻留本机已验证 | 常驻调度 | 仅选择当前快照下已审批任务，有界扫描和单并发执行；重启只核对已入账结果，运行中取消或熔断作废 lease；未部署生产凭据或服务自启动。 |
| 4a · 安装版 SDK 通过 | DSH 观察工作台 | 默认关闭的可分发 Bundle；安装版 SDK 的角色、实际 UDS 重连及卸载已验证。现用页面的安装、认证及视觉验收仍待授权后执行。 |
| 4b-1 · 本机已验证 | Owner 离线确认协议 | 无副作用的 Archive Breaker 预览、固定消息签名和离线验证；不是执行授权。见 [Owner 信任边界](owner-approval-boundary.md)。 |
| 4b-2 | Owner 审批写闭环 | 配置独立于可程序化 Owner peer 的操作者确认及信任锚，原子消费确认和意图，再执行、查询及恢复同一意图。 |
| 5 | 平台、引擎与发布 | Linux 沙箱与宿主资源上限、Agda/Rocq 独立 T2、Lean 全仓与远端发布校验分别记录可用环境和验收结果。 |

不把本机 Seatbelt 或浏览器夹具视为其他目标宿主的验收。不会把 Oracle、模型输出或索引元数据作为证明授权，也不会为兼容性提供非沙箱回退。需要宿主部署、远端权限或生产凭据时单独确认；不得用夹具通过替代。
